# 已知问题与限制

## 功能

- 撤销（Snackbar Undo）尚未实现；删除操作都会先弹出确认。
- 待规划列表里的计划还不能拖出到时间轴。
- 无障碍（TalkBack）未系统检查。

## 备份

- WebDAV 云端只保留一个滚动文件 `chronota-latest.json`，不保存历史版本；
  需要历史请用本地导出。
- 从文件或云端恢复都会整体替换本机数据，且不可撤销；操作前会先确认。
- 自动备份依赖系统的精确闹钟与后台策略，可能被系统延迟。

## 平台

- 提醒与自动备份受通知权限、精确闹钟权限和省电策略影响。
- 默认分类只在新装（数据库为空）时补入，不会补回用户主动删除的默认分类。
- 运行中的计时器不进入备份：那是进行中的会话，不是已存数据。

## 验证状态

- 构建、JVM/Robolectric 测试与 Lint 在本地与 CI 均通过。
- 真机与设备端自动化测试尚未执行；模拟器上的手工检查与 JVM 测试分别记录，
  前者不能代替后者，后者也不能代替前者。
