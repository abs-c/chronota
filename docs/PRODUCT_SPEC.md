# Chronota 产品说明

一个用于计划和记录的 Android 时间管理应用。本地优先，无账号、无云同步。

## 核心理念

- **Plan** 是原本打算做什么，**Record** 是实际做了什么，两者是相互独立的实体。
- 记录可以从计划复制内容，但不建立关联；计划永远不会变成记录。
- 计时器与番茄钟最终产出记录。
- 未来主要用来做计划，过去主要用来记录，现在用来执行。

## 领域模型

| 实体 | 说明 |
| --- | --- |
| Category | 两级分类，子分类挂在一级分类下；图标与颜色属于子分类 |
| PropertyDefinition | 子分类上的自定义属性：文本（单行/多行）、数字、是否、单选、多选、评分 |
| Plan | 计划：日历日期、可选的本地起止时间、全天、循环规则、提醒与属性值 |
| Record | 记录：绝对起止时间与属性值，可以脱离计划独立存在 |
| TimerSession / TimerSlice | 进行中的计时会话与分片 |
| Reminder | 计划开始前的提醒，可设多个 |
| Goal | 目标：按标题与属性筛选记录，把统计结果和目标值比较 |

## 规则

- 逻辑日由集中的领域逻辑计算：日界线可在设置里调整（默认 00:00）。今日、日程、
  日历与统计共用同一条规则，跨边界的时长按覆盖范围分摊。
- 计划保留本地日期与时区，记录保存绝对时间；夏令时的无效时刻拒绝保存。
- 循环计划只保存规则，实例由领域逻辑按可见范围展开，不写入数据库。
- 历史计划默认锁定，可在设置中允许编辑。
- 业务数据存 Room，偏好存 DataStore。
- 数据库升级必须是非破坏性的：schema 1 → 11 的每一步都有 Migration 与迁移测试。
- 不写入演示数据。首次启动补入默认分类（Sonata/学习、Nocturne/观影、Waltz/睡眠），
  同名分组复用，被用户删除后不会重新补回。

## 功能

四栏：今日、计划、记录、我的。

- **今日**：双栏时间轴，计划在左、记录在右，全天计划单独显示；周日期条与周视图开关，
  可返回当天；长按空白创建，拖动调整时间。
- **计划**：时间轴与目标两个标签，均分顶栏；时间轴可按分类筛选、切换详情与时间排序，
  循环计划在这里设置重复规则。
- **目标**：按“标题正则 + 属性筛选”圈定记录，设置指标、方向与目标值，
  显示进度，达到后可重启，已完成周期作为历史保留。
- **记录**：日程与日历浏览记录（日历可叠加计划）；统计支持日/周/月/自定义范围
  （最多 366 天），含分类占比、每日趋势与活动日历，可按分类下钻。
- **计时**：统一入口选择正计时或番茄钟，支持暂停、恢复与结束，状态与已填属性持久保存；
  必填属性在开始前校验；暂停与休息不计入记录。
- **分类与属性**：两级分类管理，内置 Lucide 线性图标与按 OKLCH 生成的配色网格，
  可拖动排序与换组；删除分类会先显示影响范围，确认后级联删除其内容。
- **提醒**：多个开始前提醒，开机、改时间或换时区后自动重排。
- **备份**：可导出与导入本地文件；可配置 WebDAV 的测试连接、立即备份、从云端恢复，
  以及按设定钟点的每日自动备份。恢复在单个事务内完成。
- **外观与偏好**：浅色/深色/跟随系统，语言跟随系统、English 或简体中文；
  另有悬浮球动作、日界线、每周起始日、事项名称优先级等设置。

## 界面与设计

- 四个主页面加悬浮玻璃底栏与相邻操作球，主页面没有固定标题栏。
- 控件 48dp，底栏与操作球 56dp，间距遵循 4dp 网格；尺寸、圆角与颜色来自统一 Design Tokens。
- 页面是分组的灰色底，内容浮在它上面：卡片、设置分组、日历与时间轴、输入框都是白色纸面，
  由共用的 `cardSurface` 抬升 1dp；只有悬浮的玻璃底栏与操作球用 2dp。
- 时间、时长与计数使用系统字体的等宽数字（tabular figures），不用等宽字体。
- 编辑器是实心中央面板配统一遮罩，分类选择复用分组网格。
- 文案不写死在代码里，英文与简体中文资源同时维护，浅色与深色一起支持。

## 技术

Kotlin + Jetpack Compose + Room + DataStore + Navigation Compose，单个 `app` 模块。
minSdk 26，compileSdk 与 targetSdk 36。当前版本 0.1.2。
测试为 JVM 与 Robolectric（131 个用例），构建与 Lint 通过。
