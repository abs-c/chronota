## M0 交付范围（0.1.0 历史记录）

- 单 `app` 模块，固定 Gradle / AGP / Kotlin / Compose 依赖。
- 三个一级页面与分类、设置二级路由，稳定返回与导航状态。
- 浅色、深色和跟随系统，偏好通过 DataStore 保存。
  为保证主题切换可持续使用，提前实现 M1 中这部分偏好存储。
- 系统字体、统一中性色、字号/间距/圆角/触摸目标/outline 图标。
- 英文和简体中文资源；Android 13+ 注册系统应用语言入口。
- 业务页目前为空态；不生成假数据、不展示不能执行的创建按钮。
- 尚无 Room 数据库，因此此阶段没有业务 schema 或 Migration。

## M1 开始前的设计约束

- Category 的 parentId 保留扩展性，第一版仓储限制两级。
- 一级分类没有颜色/图标；业务实体仅引用二级分类。
- 删除被引用分类应明确拒绝或要求迁移，不能静默级联删除历史。
- Plan 保留日期、可空本地时间、跨日结束日期/偏移的日历语义。
  Record 使用绝对时间。DST 的歧义和缺失时间必须有统一解析策略。
- 首个正式 schema 导出到 `app/schemas`；后续升级必须带 Migration。
- 领域规则使用可注入 Clock / ZoneId，在 UI 之外集中验证。

### 循环计划与界面一致性 · 0.7.0 · 2026-09-09

循环（新功能）

- `Plan` 增加 `recurrence`、`recurrenceInterval`、`recurrenceUntil`，Room schema 5，
  提供 4 → 5 非破坏迁移：只新增带默认值的列，不重写既有行。
- 循环规则集中在 `domain/Recurrence.kt`：以计划自身日期为锚点按天/周/月/年步进，
  月内 31 号自动落到短月最后一天，结束日期为闭区间，单次展开上限 400 条。
- 时间轴、日/周/月历按可见范围展开实例；日程列表显示下一次实例，副标题标注「每天」等；
  循环计划关闭拖拽移动，避免把整天序列整体挪走。
- 提醒跟随下一个未开始的实例；实例投递后清除投递标记，下一实例重新排程。
- 计划编辑器新增「循环」行（不循环/每天/每周/每月/每年 + 间隔 + 重复结束）；
