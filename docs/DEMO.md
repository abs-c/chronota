# 0.6.0 Demo 导览

Demo 直接位于应用内，使用已有数据与真实编辑流程，不向生产数据库写入演示历史。

| 主入口 | 第一层 | 第二层与交互 |
| --- | --- | --- |
| 今日 | 双栏时间轴 | 周日期条、返回今日、长按创建、拖动编辑 |
| 计划 | 日程 | 全部／二级分类筛选，详情开关，正序／倒序 |
| 计划 | 日历 | 日／周／月；可叠加记录 |
| 回顾 | 日程 | 全部／二级分类筛选，详情开关，正序／倒序 |
| 回顾 | 日历 | 日／周／月；可叠加计划 |
| 回顾 | 统计 | 日／周／月／自定义范围；占比／趋势／活动日历 |
| 我的 | 显示与行为设置 | 新一天开始时间、事项名称显示、语言、外观、悬浮球、计时 |

日程和日历采用连续底色，保留选中状态与必要输入背景。计划页右下角固定新建计划，回顾页固定新建记录；这两页不再显示列表新增按钮。设置的短按动作只用于今日与我的，长按仍可打开动作菜单。

日历默认只显示本页的数据。右侧小开关叠加另一种数据，关闭后同时隐藏对应图例。所有日历尺度只显示当前时刻之后的计划、之前的记录；跨当前时刻的事项只绘制相应部分。月历选择日期后显示当日列表，“查看当日”进入时间轴。

统计默认本月。顶部筛选一级分类，随后可以选择二级分类；圆环下方列出二级分类时长与占比，点击下钻。趋势柱状图按天累计；活动日历用颜色深浅表达时长，点击日期进入日统计。没有记录时显示真实空态，不制造数据。

## 日期归属

“我的 → 新一天开始时间”默认 00:00。设为 04:00 后，9 月 9 日 03:00 归入 9 月 8 日：
- 今日与日历的时间轴从 04:00 开始，延续至下一自然日 04:00。
- 日程按事项开始时刻所属的逻辑日期分组。
- 月历和周历显示跨日事项实际覆盖的各天。
- 统计把 03:30–04:30 的时长分别计入两天，每天 30 分钟。

此设置只改变浏览和统计边界，不改写实际时间。全天计划仍按所选日历日期保存；显示时覆盖对应逻辑日。夏令时边界由共享时间规则解析。

## 表单

分类在最上方，其后是标题和自定义属性，最后是起止时间。标题默认提供，可移除或重新添加，最多一个。留空会显示分类名；“事项名称显示”可设置优先显示分类名。没有分类和标题时显示“未分类”，保存的标题仍为空，因此分类改名后显示也会跟随。

日期与时间在同一中央面板编辑，一次确认提交。长文本保留中文字体上下空间，初始三行并随输入增高。评分为 0–100 整数，星级按最近半星折算，滑动条手柄缩短。

已有分类属性和数据保持不变；仍使用 Room schema 4，本轮偏好保存于 DataStore，不需要数据库升级。
