# 界面导览

四个主页面：今日、计划、回顾、我的。主页面没有固定标题栏，右下角是操作球，底部是玻璃底栏。

| 页面 | 一级 | 二级与交互 |
| --- | --- | --- |
| 今日 | 时间轴 | 周日期条、返回今日、长按创建、拖动编辑；计划在左、记录在右 |
| 计划 | 日程 | 按分类筛选、详情开关、时间正序或倒序 |
| 计划 | 日历 | 日 / 周 / 月，可叠加记录 |
| 计划 | 目标 | 新建与编辑目标，查看进度与历史 |
| 回顾 | 日程 | 记录的日程浏览 |
| 回顾 | 日历 | 日 / 周 / 月，可叠加计划 |
| 回顾 | 统计 | 日 / 周 / 月 / 自定义范围，占比、趋势、活动日历 |
| 我的 | 设置 | 分类、时间、显示、外观与语言、交互、备份、提醒 |

- 操作球短按执行设置里选定的动作，长按展开四个选项；可拖入选项执行，拖出取消。
- 计划页与回顾页的操作球固定为“新建计划”和“新建记录”。
- 编辑器是实心中央面板，日期与时间在同一个面板里一次确认。
- 日历只画当前时刻之后的计划与之前的记录，跨当前时刻的事项只画对应部分。
